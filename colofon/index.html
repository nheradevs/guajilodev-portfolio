Cómo está construido este sitio

HTML, CSS y JavaScript escritos a mano. Sin frameworks, sin build y sin dependencias de terceros.

Sin build y sin dependencias

Cada página es un archivo HTML. No hay paso de compilación, no hay npm y no hay librerías de terceros en el navegador. Lo que está en el repositorio es lo que se publica.

Tipografía

Tres familias autoalojadas en woff2, con licencia SIL Open Font License: Archivo para títulos e interfaz, Source Serif 4 para el cuerpo de los artículos y JetBrains Mono para etiquetas y código.

Entre las tres pesan unos 134 KB. El subset latin-ext solo se descarga si una página usa un carácter que lo necesita.

Color y contraste

Un solo tema, oscuro. La paleta sale de tres tonos base. El resto se midió para cumplir WCAG 2.2 AA, las pautas de accesibilidad del W3C. El texto principal tiene un contraste de 10,9:1 sobre el fondo y los metadatos, el texto más tenue, 5,5:1.

Seguridad

La política de seguridad de contenido (CSP) bloquea todo lo que no venga del propio sitio. Las cabeceras viven en el archivo _headers de Netlify, porque directivas como frame-ancestors no funcionan dentro de una etiqueta meta.

El JavaScript no usa innerHTML ni eval. El DOM se arma con createElement y textContent. El detalle está en cómo apliqué el OWASP Top 10 en este sitio.

Si encuentras una vulnerabilidad, escríbeme por correo antes de publicarla y coordinamos el arreglo. El contacto también está en security.txt.

Privacidad

Sin cookies, sin analítica y sin trackers. Lo único que se guarda en tu navegador es la preferencia de idioma, y solo si eliges una.

Accesibilidad

Todo el contenido y la navegación funcionan sin JavaScript. Sin él solo se pierde el botón de copiar de los bloques de código. El foco se ve siempre y el movimiento se apaga si tu sistema pide menos animación.

JavaScript

Un solo archivo de unos 5 KB. Abre el menú en pantallas chicas, fija la cabecera, ofrece la versión en inglés y copia los bloques de código.
