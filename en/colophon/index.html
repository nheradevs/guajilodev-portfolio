How this site is built

HTML, CSS, and JavaScript written by hand. No frameworks, no build step, and no third-party dependencies.

No build, no dependencies

Every page is an HTML file. There’s no compile step, no npm, and no third-party libraries in the browser. What’s in the repository is what gets published.

Typography

Three self-hosted families in woff2, under the SIL Open Font License: Archivo for headings and interface, Source Serif 4 for article body text, and JetBrains Mono for labels and code.

The three weigh about 134 KB together. The latin-ext subset only downloads if a page uses a character that needs it.

Color and contrast

One theme, dark. The palette comes from three base tones, and the rest was measured to meet WCAG 2.2 AA (the W3C accessibility guidelines). Body text has a 10.9:1 contrast ratio against the background, and metadata, the faintest text, has 5.5:1.

Security

The Content Security Policy (CSP) blocks anything that doesn’t come from the site itself. The headers live in Netlify’s _headers file, because directives like frame-ancestors don’t work inside a meta tag.

The JavaScript doesn’t use innerHTML or eval. The DOM is built with createElement and textContent. The details are in how I applied the OWASP Top 10 to this site.

If you find a vulnerability, email me before publishing it and we’ll coordinate the fix. The contact is also in security.txt.

Privacy

No cookies, no analytics, and no trackers. The only thing stored in your browser is your language preference, and only if you choose one.

Accessibility

All content and navigation work without JavaScript. Without it, you only lose the copy button on code blocks. Focus is always visible, and motion turns off if your system asks for less animation.

JavaScript

One file of about 5 KB. It opens the menu on small screens, pins the header, offers the Spanish or English version, and copies code blocks.
